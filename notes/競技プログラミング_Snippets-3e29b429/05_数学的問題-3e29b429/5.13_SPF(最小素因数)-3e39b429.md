# 5.13 SPF（最小素因数）

Source: https://www.notion.so/3e39b4299e6181e7bb92e9e13a234975

---

<callout icon="⚡" color="blue_bg">
	多数の整数を素因数分解するときは、各数の**最小素因数 SPF（Smallest Prime Factor）**を前計算する。1回だけなら通常の試し割りで十分。
</callout>
## 判断基準
- 1個〜少数の整数を分解：試し割り `O(√N)`
- `1..N` の範囲で大量に分解：SPFを前計算
- 値の最大値が非常に大きい：SPF配列は作らず、別の方法を検討
## SPF構築
```python
from math import isqrt

def build_spf(n):
    """0以上n以下の各数について最小素因数を返す"""
    spf = list(range(n + 1))

    for p in range(2, isqrt(n) + 1):
        if spf[p] == p:  # pは素数
            for multiple in range(p * p, n + 1, p):
                if spf[multiple] == multiple:
                    spf[multiple] = p

    return spf
```
## SPFを使った素因数分解
```python
def factorize_with_spf(n, spf):
    factors = {}

    while n > 1:
        p = spf[n]
        factors[p] = factors.get(p, 0) + 1
        n //= p

    return factors
```
## 使用例
```python
A = [12, 18, 100, 999]
spf = build_spf(max(A))

for x in A:
    print(x, factorize_with_spf(x, spf))

# 12  {2: 2, 3: 1}
# 18  {2: 1, 3: 2}
# 100 {2: 2, 5: 2}
# 999 {3: 3, 37: 1}
```
## 応用
- 各数の異なる素因数の個数
- 素因数の総数（重複込み）
- 約数個数・約数総和
- 平方因子を持たない数（square-free）の判定
- 配列の各要素を素因数単位で集計する
## 計算量
- SPF構築：時間 `O(N log log N)` 程度、メモリ `O(N)`
- 1回の素因数分解：割る回数に比例し、最大でも `O(log N)`
## よくあるミス
- `factorize_with_spf(x, spf)` では `x < len(spf)` が必要
- `max(A)` が巨大なのにSPF配列を作り、MLEになる
- `1` の素因数分解結果は `{}`
- SPFは「素数一覧」ではなく、各整数の最小素因数を持つ配列
