# 5.11 素因数分解

Source: https://www.notion.so/3e39b4299e6181d8910fee8bc95dde1a

---

<callout icon="🧩" color="blue_bg">
	1つの整数を「どの素数が何個掛かっているか」に分解する。`360 = 2^3 × 3^2 × 5` のように扱う。
</callout>
## 実戦テンプレ {toggle="true"}
	前提：`n >= 1`。戻り値は `{素数: 指数}` の辞書。
	```python
def prime_factorize(n):
    factors = {}
    p = 2

    while p * p <= n:
        while n % p == 0:
            factors[p] = factors.get(p, 0) + 1
            n //= p
        p += 1

    if n > 1:
        factors[n] = factors.get(n, 0) + 1

    return factors
	```
	```python
factors = prime_factorize(360)
print(factors)  # {2: 3, 3: 2, 5: 1}
	```
## 最後に残った `n` を追加する理由 {toggle="true"}
	ループ終了時に `n > 1` なら、その `n` は素数。たとえば `n = 14` では `2` を取り除いたあと `7` が残るため、最後に追加する必要がある。
## よく使う応用 {toggle="true"}
	### 異なる素因数の個数 {toggle="true"}
		```python
answer = len(prime_factorize(n))
		```
	### 素因数の総数（重複込み） {toggle="true"}
		```python
answer = sum(prime_factorize(n).values())
		```
	### 約数の個数 {toggle="true"}
		`n = p1^e1 × p2^e2 × ...` の約数個数は `(e1 + 1)(e2 + 1)...`。
		```python
def divisor_count(n):
    answer = 1
    for exponent in prime_factorize(n).values():
        answer *= exponent + 1
    return answer
		```
	### 約数の総和 {toggle="true"}
		```python
def divisor_sum(n):
    answer = 1
    for p, exponent in prime_factorize(n).items():
        answer *= (p ** (exponent + 1) - 1) // (p - 1)
    return answer
		```
	### オイラーのφ関数 {toggle="true"}
		`1` 以上 `n` 以下で `n` と互いに素な整数の個数。
		```python
def euler_phi(n):
    answer = n
    for p in prime_factorize(n):
        answer = answer // p * (p - 1)
    return answer
		```
## 計算量 {toggle="true"}
	- 試し割り：時間 `O(√N)`、追加メモリは素因数の種類数ぶん
	- 多数の値を分解する場合は、毎回試し割りせずSPFを使う
## よくあるミス {toggle="true"}
	- `n = 1` の結果は空の辞書 `{}`
	- ループ後に残った `n > 1` を追加し忘れる
	- 割り切れる間は `if` ではなく `while` で割る
	- 分解対象を書き換えるため、元の値が必要なら別変数に保存する
