# 5.12 約数列挙・約数の個数

Source: https://www.notion.so/3e39b4299e6181718ab1cd98359fb68a

---

<callout icon="🔢" color="blue_bg">
	`n` の約数をすべて求めるときは、`d` と `n // d` がペアになることを利用して `√n` まで調べる。
</callout>
## 実戦テンプレ
前提：`n >= 1`。昇順の約数一覧を返す。
```python
def divisors(n):
    small = []
    large = []
    d = 1

    while d * d <= n:
        if n % d == 0:
            small.append(d)
            if d * d != n:
                large.append(n // d)
        d += 1

    return small + large[::-1]
```
```python
print(divisors(36))
# [1, 2, 3, 4, 6, 9, 12, 18, 36]
```
## 2つの配列に分ける理由
`d` は小さい順に見つかる一方、対応する `n // d` は大きい順に見つかる。`large` を最後に逆順にすれば、`sort()` なしで全体を昇順にできる。
## 適用例：積が `n` になる組を調べる
```python
from math import isqrt

for a in range(1, isqrt(n) + 1):
    if n % a == 0:
        b = n // a
        # a * b == n を満たす組 (a, b)
```
次のような問題でよく使う。
- 長方形の辺 `(a, b)` を列挙する
- `a * b = n` を満たす組を調べる
- 約数のうち条件を満たすものを探す
- 公約数候補を列挙する
## 約数の個数だけ欲しい場合
```python
count = len(divisors(n))
```
素因数分解済みなら、各指数に1を足した積を使う方が自然。
```python
count = 1
for exponent in prime_factorize(n).values():
    count *= exponent + 1
```
## 計算量
- 列挙：時間 `O(√N)`
- 戻り値：`O(約数の個数)`
## よくあるミス
- `d * d == n` のとき、平方根を2回追加してしまう
- `range(1, isqrt(n))` として平方根を調べ損ねる
- `n = 1` の約数は `[1]`
- 順序が必要なのに、大小の約数を同じ配列へ交互に追加してそのまま使う
