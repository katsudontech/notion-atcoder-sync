## 推奨テンプレ①：距離だけ（基本はこちら）
```python
from collections import deque


def bfs(G, start):
    N = len(G)
    dist = [-1] * N

    dist[start] = 0
    q = deque([start])

    while q:
        v = q.popleft()

        for nv in G[v]:
            if dist[nv] != -1:
                continue

            dist[nv] = dist[v] + 1
            q.append(nv)

    return dist
```
### 使い方
```python
start = 0
dist = bfs(G, start)

print(dist[N - 1])
```
- `dist[v]`：start から v までの最短距離
- `dist[v] == -1`：到達不能
- 到達可能かどうかだけ知りたい場合も、この版で十分
## 推奨テンプレ②：距離＋経路復元（必要なときだけ）
```python
from collections import deque


def bfs_with_prev(G, start):
    N = len(G)
    dist = [-1] * N
    prev = [-1] * N

    dist[start] = 0
    prev[start] = start
    q = deque([start])

    while q:
        v = q.popleft()

        for nv in G[v]:
            if dist[nv] != -1:
                continue

            dist[nv] = dist[v] + 1
            prev[nv] = v
            q.append(nv)

    return dist, prev


def restore_path(prev, goal):
    if prev[goal] == -1:
        return []

    path = []
    v = goal

    while prev[v] != v:
        path.append(v)
        v = prev[v]

    path.append(v)
    path.reverse()

    return path
```
### 使い方
```python
start = 0
goal = N - 1

dist, prev = bfs_with_prev(G, start)
path = restore_path(prev, goal)

print(dist[goal])
print(path)
```
### 使い分け
- **距離・到達判定だけ** → `bfs`
- **実際に通った最短経路も欲しい** → `bfs_with_prev` + `restore_path`
- `prev` は便利だが、不要なら作らない。特にBFSを何度も呼ぶ問題では `[-1] * N` の初期化回数にも注意する
## 何を記録しているか
- `dist[v]`：開始頂点から頂点 `v` までに通る辺の最小本数
- `prev[v]`：その最短経路で、頂点 `v` の直前にいた頂点
- `path`：`start` と `goal` を含む頂点番号の配列
たとえば経路が 0 → 2 → 5 なら、復元結果は \[0, 2, 5\] になる。
## 使う場面
- 重みなしグラフの最短距離
- 最短経路上の頂点を列挙したい場合
- 迷路
- 状態遷移の最短手数
## 注意事項
- 頂点をキューへ追加した時点で `dist` を更新する。経路復元版では同時に `prev` も更新する
- 辺の重みがすべて同じでない場合、通常のBFSでは最短距離を求められない
- 最短経路が複数ある場合、隣接リストで先に探索された経路を1つだけ返す
- `prev[start] = start` とすることで、経路復元の終了地点を表している
- 経路全体をキューへ入れる方法は、同じ経路情報を何度もコピーしてメモリを消費しやすい
- ちょっと改造したら、開始地点を複数指定できるようになる。炎や感染が複数個所から広がっていく感じの問題を処理できるようになる。
## 計算量
- BFS：O(N + M)
- 経路復元：O(経路の長さ)
- 追加メモリ：O(N)
## よくあるミス
- `prev[nv] = v` を記録し忘れる
- 到達不能なのに経路復元を始める
- `path.reverse()` を忘れ、goalからstartの逆順で返してしまう
- 重み付きグラフに通常のBFSを使う
