# 9.11 最小共通祖先（LCA）

Source: https://www.notion.so/4179b4299e6181eaa155cf7b4bb1d90c

---

<callout icon="💡" color="blue_bg">
	一般の木で「2頂点の最小共通祖先」や「2頂点間の距離」を何度も求めるためのテンプレート。前計算は1回だけ行い、問い合わせごとに使い回す。
</callout>
## 1. テンプレート {toggle="true"}
	前提：N ≥ 1、頂点番号は0-indexed、Gは連結な無向の木の隣接リスト。辺や根は問い合わせの途中で変更しない。追加のimportは不要。
	```python
def build_lca(G, root=0):
    n = len(G)
    log = n.bit_length()

    depth = [-1] * n
    parent = [root] * n

    # 各頂点の親と深さを求める
    depth[root] = 0
    stack = [root]

    while stack:
        v = stack.pop()

        for nv in G[v]:
            if depth[nv] != -1:
                continue

            depth[nv] = depth[v] + 1
            parent[nv] = v
            stack.append(nv)

    # jump[j][v]：vの2**j個上の祖先
    jump = [parent]

    for _ in range(1, log):
        prev = jump[-1]
        jump.append([prev[prev[v]] for v in range(n)])

    return jump, depth


def lca(u, v, jump, depth):
    # uを深い側にする
    if depth[u] < depth[v]:
        u, v = v, u

    # ① 深さをそろえる
    diff = depth[u] - depth[v]

    for j in range(len(jump)):
        if (diff >> j) & 1:
            u = jump[j][u]

    if u == v:
        return u

    # ② 合流しない範囲で、両方を上へ進める
    for j in range(len(jump) - 1, -1, -1):
        if jump[j][u] != jump[j][v]:
            u = jump[j][u]
            v = jump[j][v]

    # ③ 両方の親がLCA
    return jump[0][u]


def tree_distance(u, v, jump, depth):
    ancestor = lca(u, v, jump, depth)
    return depth[u] + depth[v] - 2 * depth[ancestor]
	```
	根の親は根自身とする。根より上へ進もうとしても根にとどまり、-1による添字ミスを防ぐ。
## 2. 使い方 {toggle="true"}
	- `jump, depth = build_lca(G, root=0)`：親の表と深さを前計算する。
	- `lca(u, v, jump, depth)`：最小共通祖先の頂点番号を返す。
	- `tree_distance(u, v, jump, depth)`：2頂点を結ぶ道の辺数を返す。
	```plain text
    0
   / \
  1   2
 / \
3   4
	```
	```python
G = [
    [1, 2],
    [0, 3, 4],
    [0],
    [1],
    [1],
]

jump, depth = build_lca(G)

print(lca(3, 4, jump, depth))            # 1
print(tree_distance(3, 4, jump, depth))  # 2
print(lca(3, 2, jump, depth))            # 0
print(tree_distance(3, 2, jump, depth))  # 3
print(lca(1, 3, jump, depth))            # 1（片方が祖先）
print(lca(4, 4, jump, depth))            # 4
print(tree_distance(4, 4, jump, depth))  # 0
	```
	入力が「N Q」「N-1本の辺」「Q個の距離の問い合わせ」で、頂点番号が1始まりの場合：
	```python
import sys

input = sys.stdin.readline

N, Q = map(int, input().split())
G = [[] for _ in range(N)]

for _ in range(N - 1):
    a, b = map(int, input().split())
    a -= 1
    b -= 1
    G[a].append(b)
    G[b].append(a)

jump, depth = build_lca(G)

for _ in range(Q):
    u, v = map(int, input().split())
    print(tree_distance(u - 1, v - 1, jump, depth))
	```
	上の3関数と合わせて使う。LCAの頂点番号を1始まりで出力する場合は、返り値に1を足す。距離には1を足さない。
## 3. 何を求めるものか {toggle="true"}
	LCAは、根を決めた木で、2頂点に共通する祖先のうち最も深い頂点。「両方から親をたどって最初に合流する場所」と捉える。頂点自身も祖先に含める。
	「最小」は頂点番号が最小という意味ではない。一般の木では頂点番号の大小と深さは無関係。
	距離は、両側から合流地点までの移動回数を足せばよい。
	```plain text
uからLCAまで = depth[u] - depth[LCA]
vからLCAまで = depth[v] - depth[LCA]

距離 = depth[u] + depth[v] - 2 * depth[LCA]
	```
	ここでの距離は辺の本数。経路上の頂点数を求める問題なら、距離に1を足す。
## 4. アルゴリズムの考え方 {toggle="true"}
	まずは親を1個ずつたどる方法を理解する。
	```python
def lca_naive(u, v, parent, depth):
    while depth[u] > depth[v]:
        u = parent[u]

    while depth[v] > depth[u]:
        v = parent[v]

    while u != v:
        u = parent[u]
        v = parent[v]

    return u
	```
	基本は「深さをそろえる → 両方を一緒に上げる → 合流する」。この方法は1回あたりO(木の高さ)、最悪O(N)。
	ダブリング版は、同じ考え方で移動を高速化する。
	1. `jump[j][v]` に、2**j個上の祖先を前計算する。2**j個上へ2回進むと、2\*\*(j+1)個上に着く。
	2. 深さの差を二進数に分解して、深い側だけを上げる。差が13なら8+4+1個上へ進む。
	3. 同じ頂点になったら、その頂点がLCA。
	4. 異なる場合、大きなジャンプから順に試す。ジャンプ先が異なるなら、まだLCAより下なので両方を進める。
	5. 最後は両方がLCAのすぐ下にいるため、親を返す。
	ジャンプ先が同じときに進めないのは、LCAそのものや、それより上まで飛んでしまう可能性があるため。
## 5. 使う場面と計算量 {toggle="true"}
	「同じ木について、2頂点間の距離や共通祖先を何度も聞かれる」ときに候補にする。
	- 前計算：O(N log N)。
	- LCA・距離の問い合わせ1回：O(log N)。
	- Q回の問い合わせを含む全体：O((N + Q) log N)。
	- 前計算表のメモリ：O(N log N)。隣接リストはO(N)。
	問い合わせが1回だけならDFSやBFSで距離を求める方法でも十分。木が浅いなら親を1個ずつたどる方法も候補。
	Nが20万なら表は約18段。Pythonでは表のメモリも制限と比較する。
## 6. 注意事項・よくあるミス {toggle="true"}
	- 頂点番号の大小で上げる側を決めない。一般の木では深さで判断する。
	- 深さをそろえた直後の `if u == v` を忘れない。片方がもう片方の祖先の場合に必要。
	- 両方を上げるループは大きいジャンプから試す。
	- 最後は `u` ではなく、その親 `jump[0][u]` を返す。
	- 前計算を問い合わせごとにやり直さない。
	- 入力の1始まりと内部の0始まりを混ぜない。
	- N=1、u=v、片方が祖先、根を含む問い合わせでも使える。
	- 非連結グラフや閉路のある一般グラフには、このテンプレートをそのまま使わない。
	- 根を変えるとLCAが変わることがある。根や辺を変更したら前計算も作り直す。
	- `tree_distance` は辺数を返す。重み付きの木の経路の重み合計なら、別途求めた根からの重み合計 `dist` で `dist[u] + dist[v] - 2 * dist[lca]` を使う。LCA用の `depth` は辺数のままにする。
	- 親・深さは反復DFSで求めているため、細長い木でも再帰の深さ制限にかからない。
