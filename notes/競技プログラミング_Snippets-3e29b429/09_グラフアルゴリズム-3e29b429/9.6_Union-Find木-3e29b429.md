## AtCoder Library版 {toggle="true"}
	```python
# unionfind構築
uf = DSU(N)
# a, bを同じグループに
uf.merge(a, b)
# a, bは同じグループか。
same = uf.same(a, b)

size = uf.size(a)
groups = uf.groups()
	```
## 使う場面 {toggle="true"}
	- 辺を追加しながら連結判定する
	- 連結成分数や各成分のサイズを管理する
	- Kruskal法
## 注意事項 {toggle="true"}
	- 辺の削除には基本的に使えない
	- groups() は全頂点をまとめるため、頻繁に呼ばない
## 計算量 {toggle="true"}
	- merge / same：償却ほぼO(1)
