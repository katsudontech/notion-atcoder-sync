## AtCoder Library版
```python
from atcoder.dsu import DSU

uf = DSU(N)
uf.merge(a, b)
same = uf.same(a, b)
size = uf.size(a)
groups = uf.groups()
```
## 使う場面
- 辺を追加しながら連結判定する
- 連結成分数や各成分のサイズを管理する
- Kruskal法
## 注意事項
- 辺の削除には基本的に使えない
- groups() は全頂点をまとめるため、頻繁に呼ばない
## 計算量
- merge / same：償却ほぼO(1)
