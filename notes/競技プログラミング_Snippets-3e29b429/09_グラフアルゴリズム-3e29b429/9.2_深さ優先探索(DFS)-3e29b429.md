# 9.2 深さ優先探索（DFS）

Source: https://www.notion.so/3e29b4299e6181b98456d61cd9521edc

## コピペ用①：一般グラフの到達判定
```python
import sys
sys.setrecursionlimit(10**6)


def dfs(G, start):
    visited = [False] * len(G)

    def visit(v):
        visited[v] = True
        for nv in G[v]:
            if not visited[nv]:
                visit(nv)

    visit(start)
    return visited
```
### 使い方
```python
visited = dfs(G, 0)
print(visited[N - 1])  # 頂点0から頂点N-1へ到達できるか
```
- `G[v]`：頂点 `v` の隣接頂点のリスト。頂点番号は0始まり。
- `visited[v]`：到達できれば `True`、できなければ `False`。
- 閉路のあるグラフにも使える。距離・経路は記録しない。
## コピペ用②：木の探索（行きがけ・帰りがけ）
```python
import sys
sys.setrecursionlimit(10**6)


def dfs(v, parent):
    # 行きがけ：v に入ったときの処理

    for nv in G[v]:
        if nv == parent:
            continue
        dfs(nv, v)

    # 帰りがけ：すべての子の処理が終わった後
```
### 使い方
```python
dfs(0, -1)  # 頂点0を根にする。根の親は -1
```
- `G` は事前に作る無向木の隣接リスト。コメント部分に必要な処理を追加する。
- `parent` は「今の頂点へ来る直前にいた頂点」。親へ戻る辺を飛ばすために使う。
- 子へ進むときは `dfs(nv, v)`。子から見ると、現在の `v` が親になる。
- 行きがけ：深さの記録やパスへの追加。帰りがけ：子の結果の集計や状態の復元。
## コピペ用③：木の親・深さ・探索順が必要な場合
```python
def dfs_tree(G, root=0):
    N = len(G)
    parent = [-1] * N
    depth = [-1] * N
    order = []
    stack = [root]
    depth[root] = 0

    while stack:
        v = stack.pop()
        order.append(v)
        for nv in G[v]:
            if nv == parent[v]:
                continue
            parent[nv] = v
            depth[nv] = depth[v] + 1
            stack.append(nv)

    return parent, depth, order
```
### 使い方
```python
parent, depth, order = dfs_tree(G, 0)

# 例：部分木の頂点数を子から親へ集計
size = [1] * len(G)
for v in reversed(order):
    if parent[v] != -1:
        size[parent[v]] += size[v]
```
- `parent[v]`：根付き木での親。根は `-1`。
- `depth[v]`：根からの辺数。
- `order`：親が子より先に現れる探索順。`reversed(order)` なら子から親へ集計できる。
- 再帰を使わない木専用版。親・深さ・探索順が不要なら①または②を使う。
## コピペ用④：到達判定の反復版（再帰を避けたい場合）
```python
def dfs_iterative(G, start):
    visited = [False] * len(G)
    visited[start] = True
    stack = [start]

    while stack:
        v = stack.pop()
        for nv in G[v]:
            if visited[nv]:
                continue
            visited[nv] = True
            stack.append(nv)

    return visited
```
### 使い方
```python
visited = dfs_iterative(G, 0)
```
返り値は①と同じ。スタックへ追加するときに訪問済みにして、重複追加を防ぐ。到達判定用で、再帰版の行きがけ・帰りがけの順序をそのまま再現するものではない。
## 応用：根からのパスに重複する値があるか
```python
import sys
from collections import defaultdict
sys.setrecursionlimit(10**6)


def path_has_duplicate(G, A, root=0):
    count = defaultdict(int)
    duplicate = 0
    ans = [False] * len(G)

    def dfs(v, parent):
        nonlocal duplicate

        count[A[v]] += 1
        if count[A[v]] == 2:
            duplicate += 1
        ans[v] = duplicate > 0

        for nv in G[v]:
            if nv != parent:
                dfs(nv, v)

        if count[A[v]] == 2:
            duplicate -= 1
        count[A[v]] -= 1

    dfs(root, -1)
    return ans
```
### 使い方
```python
ans = path_has_duplicate(G, A, 0)
print(ans[N - 1])  # 根から頂点N-1までに同じ値が2回以上あるか
```
- 木専用。`A[v]` は頂点の値。`count[x]` は現在のパス上の出現数。
- **追加 → 答えを記録 → 子を探索 → 削除**。帰りがけに戻すことで、別の枝の情報が混ざらない。
- `duplicate` は2回以上出現する値の種類数。
参考問題：[AtCoder ABC448 D 公式解説](https://atcoder.jp/contests/abc448/editorial/16747)
## 注意事項
- **一般グラフは訪問済み管理が必要。** 親だけを飛ばす②③と応用例は、閉路のない無向木で使う。
- **DFSでは一般グラフの最短距離は求められない。** 重みなしの最短距離はBFS、非負の重み付き最短距離はダイクストラ法を使う。
- 再帰上限を増やしてもメモリ不足などは防げない。深いグラフの到達判定は④、木の親・深さ・集計は③が使える。
- 1回の呼び出しで探索するのは始点から到達できる範囲だけ。非連結グラフ全体を調べるなら、訪問済み配列を共有し、未訪問の頂点から探索を追加する。
- パス上の状態は帰りがけに必ず戻す。木の子へ渡す親は `parent` ではなく `v`。
## 計算量
頂点数を `N`、辺数を `M` とする。各頂点・辺での追加処理が定数時間の場合：
- 時間：`O(N + M)`。木は `O(N)`。
- 追加メモリ：`O(N)`（訪問済み配列・再帰スタックなど）。
- グラフ本体を含むメモリ：`O(N + M)`。
