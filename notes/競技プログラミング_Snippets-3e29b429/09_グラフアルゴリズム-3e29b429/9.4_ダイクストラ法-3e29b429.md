# 9.4 ダイクストラ法

Source: https://www.notion.so/3e29b4299e61812dbbfdc478fc489b31

---

<callout icon="💡" color="blue_bg">
	ダイクストラ法は、**辺の重みがすべて非負**の重み付きグラフで、始点から各頂点までの最短距離を求めるアルゴリズム。
	基本は「距離だけ求める版」を使い、**経路そのものが必要なときだけ ****`prev`**** を持つ経路復元版を使う**。
</callout>
## 実戦テンプレ①：距離だけ求める版
一番よく使う基本形。
```python
def dijkstra(G, start):
    N = len(G)
    INF = float("inf")

    dist = [INF] * N
    dist[start] = 0

    hq = [(0, start)]

    while hq:
        d, v = heappop(hq)

        # 更新前の古い候補なら使わない
        if d != dist[v]:
            continue

        for nv, cost in G[v]:
            nd = d + cost

            if nd < dist[nv]:
                dist[nv] = nd
                heappush(hq, (nd, nv))

    return dist
```
### 使い方
```python
start = 0
dist = dijkstra(G, start)

goal = N - 1
print(dist[goal])
```
### 返り値
- `dist[v]`：`start` から頂点 `v` までの最短距離
- 到達できない頂点は `float("inf")`
## 実戦テンプレ②：経路復元する版
「最短距離だけでなく、実際にどの頂点を通ったか」も必要な場合に使う。
```python
def dijkstra_with_prev(G, start):
    N = len(G)
    INF = float("inf")

    dist = [INF] * N
    prev = [-1] * N

    dist[start] = 0
    hq = [(0, start)]

    while hq:
        d, v = heappop(hq)

        if d != dist[v]:
            continue

        for nv, cost in G[v]:
            nd = d + cost

            if nd < dist[nv]:
                dist[nv] = nd
                prev[nv] = v
                heappush(hq, (nd, nv))

    return dist, prev

def restore_path(prev, goal):
    path = []

    v = goal
    while v != -1:
        path.append(v)
        v = prev[v]

    path.reverse()
    return path
```
### `prev` とは
`prev[v]` は、最短経路で頂点 `v` に来る直前にいた頂点を記録する配列。
たとえば最短経路が
`0 → 2 → 5 → 7`
なら、次のように記録される。
- `prev[2] = 0`
- `prev[5] = 2`
- `prev[7] = 5`
`goal` から `prev` を逆向きにたどることで経路を復元できる。
# 使い方
```python
start = 0
goal = N - 1

dist, prev = dijkstra_with_prev(G, start)

if dist[goal] != float("inf"):
    path = restore_path(prev, goal)
    print(dist[goal])
    print(path)
else:
    print("到達できない")
```
<callout icon="⚠️" color="yellow_bg">
	`restore_path(prev, goal)` だけでは「goal に到達できたか」は判定できないので、先に `dist[goal] != INF` を確認する。
</callout>
## 重み付きグラフの作り方
`G[v]` に `(移動先, コスト)` を入れる。
```python
G = [[] for _ in range(N)]

for _ in range(M):
    a, b, cost = map(int, input().split())
    a -= 1
    b -= 1

    G[a].append((b, cost))
    G[b].append((a, cost))  # 有向グラフなら追加しない
```
たとえば、
```python
G[0] = [(1, 3), (2, 7)]
```
なら、頂点 `0` から
- 頂点 `1` へコスト `3`
- 頂点 `2` へコスト `7`
で移動できるという意味。
## 到達判定
```python
if dist[goal] != float("inf"):
    print("到達できる")
else:
    print("到達できない")
```
## BFSとの使い分け
- **全ての辺の重みが同じ** → BFS
- **辺ごとに異なる非負の重み** → ダイクストラ法
- **負の重みを含む** → ダイクストラ法は使えない
重みがすべて `1` なら、ダイクストラ法より BFS のほうが単純で高速。
## 使う場面
- 移動コストの最小値
- 所要時間の最小値
- 運賃の最小値
- 重み付きグラフ上の最短距離
- 最短経路そのものを復元したい場合
## 計算量
頂点数を `N`、辺数を `M` とする。
- 二分ヒープを使ったダイクストラ法：`O((N + M) log N)`
- `dist`：`O(N)`
- `prev`：`O(N)`（経路復元版のみ）
- グラフ `G`：`O(N + M)`
- 経路復元：`O(経路長)`
## よくあるミス
- ヒープへ `(頂点, 距離)` ではなく、**`(距離, 頂点)`** の順で入れる
- `if d != dist[v]: continue` を忘れて古い候補まで処理する
- `G[v]` の要素を `(移動先, コスト)` の順に統一する
- 無向グラフなのに逆向きの辺を追加し忘れる
- 負の重みがあるグラフにダイクストラ法を使う
- 最短距離しか必要ないのに `prev` や経路復元処理まで入れる
## 競プロでの使い分け
<callout icon="✅" color="green_bg">
	**基本は「距離だけ版」をコピペする。**
	問題文で「最短経路を出力せよ」「実際に通る頂点を求めよ」などと要求された場合だけ、`prev` 付きの版に切り替える。
</callout>
