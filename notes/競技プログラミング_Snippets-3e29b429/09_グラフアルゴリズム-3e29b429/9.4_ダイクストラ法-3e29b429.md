## ①：距離だけ求める版 {toggle="true"}
	一番よく使う基本形。
	```python
def dijkstra(G, start):
    N = len(G)
    INF = float("inf")

    dist = [INF] * N
    dist[start] = 0

    hq = [(0, start)]

    while hq:
        d, v = heappop(hq)

        # 更新前の古い候補なら使わない
        if d != dist[v]:
            continue

        for nv, cost in G[v]:
            nd = d + cost

            if nd < dist[nv]:
                dist[nv] = nd
                heappush(hq, (nd, nv))

    return dist
	```
	### 使い方 {toggle="true"}
		```python
start = 0
dist = dijkstra(G, start)

goal = N - 1
print(dist[goal])
		```
	### 返り値 {toggle="true"}
		- `dist[v]`：`start` から頂点 `v` までの最短距離
		- 到達できない頂点は `float("inf")`
## ②：経路復元する版 {toggle="true"}
	「最短距離だけでなく、実際にどの頂点を通ったか」も必要な場合に使う。
	```python
def dijkstra_with_prev(G, start):
    N = len(G)
    INF = float("inf")

    dist = [INF] * N
    prev = [-1] * N

    dist[start] = 0
    hq = [(0, start)]

    while hq:
        d, v = heappop(hq)

        if d != dist[v]:
            continue

        for nv, cost in G[v]:
            nd = d + cost

            if nd < dist[nv]:
                dist[nv] = nd
                prev[nv] = v
                heappush(hq, (nd, nv))

    return dist, prev

def restore_path(prev, goal):
    path = []

    v = goal
    while v != -1:
        path.append(v)
        v = prev[v]

    path.reverse()
    return path
	```
	### `prev` とは {toggle="true"}
		`prev[v]` は、最短経路で頂点 `v` に来る直前にいた頂点を記録する配列。
		たとえば最短経路が
		`0 → 2 → 5 → 7`
		なら、次のように記録される。
		- `prev[2] = 0`
		- `prev[5] = 2`
		- `prev[7] = 5`
		`goal` から `prev` を逆向きにたどることで経路を復元できる。
# 使い方 {toggle="true"}
	```python
start = 0
goal = N - 1

dist, prev = dijkstra_with_prev(G, start)

if dist[goal] != float("inf"):
    path = restore_path(prev, goal)
    print(dist[goal])
    print(path)
else:
    print("到達できない")
	```
	<callout icon="⚠️" color="yellow_bg">
		`restore_path(prev, goal)` だけでは「goal に到達できたか」は判定できないので、先に `dist[goal] != INF` を確認する。
	</callout>
	## 到達判定 {toggle="true"}
		```python
if dist[goal] != float("inf"):
    print("到達できる")
else:
    print("到達できない")
		```
## 使う場面 {toggle="true"}
	- 移動コストの最小値
	- 所要時間の最小値
	- 運賃の最小値
	- 重み付きグラフ上の最短距離
	- 最短経路そのものを復元したい場合
## よくあるミス {toggle="true"}
	- ヒープへ `(頂点, 距離)` ではなく、**`(距離, 頂点)`** の順で入れる
	- `if d != dist[v]: continue` を忘れて古い候補まで処理する
	- `G[v]` の要素を `(移動先, コスト)` の順に統一する
	- 無向グラフなのに逆向きの辺を追加し忘れる
	- 負の重みがあるグラフにダイクストラ法を使う
## 計算量 {toggle="true"}
	頂点数を `N`、辺数を `M` とする。
	- 二分ヒープを使ったダイクストラ法：`O((N + M) log N)`
	- `dist`：`O(N)`
	- `prev`：`O(N)`（経路復元版のみ）
	- グラフ `G`：`O(N + M)`
	- 経路復元：`O(経路長)`
