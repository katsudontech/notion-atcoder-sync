## 1. テンプレ {toggle="true"}
	各品物を高々1回選び、重さの合計がW以下になる範囲で価値を最大化する **0/1ナップサック**。
	### 重さを添字にする版 {toggle="true"}
		`items = [(重さ, 価値), ...]` と容量 `W` を用意して使う。
		**`dp[i][c]`****：先頭i個の品物から選び、重さc以下で得られる最大価値。**<br>添字のiは品物の個数、cは容量。マスの中身は価値。答えは `ans` に入る。
		```python
# items = [(重さ, 価値), ...]
N = len(items)
dp = [[0] * (W + 1) for _ in range(N + 1)]

for i, (weight, value) in enumerate(items):
    for c in range(W + 1):
        dp[i + 1][c] = dp[i][c]  # 選ばない
        if c >= weight:         # 選ぶ
            dp[i + 1][c] = max(
                dp[i + 1][c],
                dp[i][c - weight] + value
            )

ans = dp[N][W]
		```
	### 価値を添字にする版 {toggle="true"}
		Wが大きく、価値の合計が小さいときに使う。入力の用意は重さ版と同じ。
		**`dp[i][k]`****：先頭i個の品物から選び、価値をちょうどkにするための最小重量。**<br>添字のkは価値。マスの中身は重さ。答えは `ans` に入る。
		```python
# items = [(重さ, 価値), ...]
N = len(items)
V = sum(value for _, value in items)

# INFは共通テンプレートで定義済み
dp = [[INF] * (V + 1) for _ in range(N + 1)]
dp[0][0] = 0

for i, (weight, value) in enumerate(items):
    for k in range(V + 1):
        dp[i + 1][k] = dp[i][k]
        if k >= value:
            dp[i + 1][k] = min(
                dp[i + 1][k],
                dp[i][k - value] + weight
            )

ans = max(k for k in range(V + 1) if dp[N][k] <= W)
		```
## 2. テンプレの使い方 {toggle="true"}
	必要なものは次の2つ。
	- `items`：各品物の `(重さ, 価値)` を並べたリスト。
	- `W`：重さの合計の上限。
	使う方のテンプレを `main()` の中に1段インデントして置く。2つのテンプレはどちらも `dp` と `ans` を使うため、必要な方だけ選ぶ。
	```python
items = [(2, 3), (3, 4)]
W = 5

# ここに、上のテンプレのどちらかを貼る

print(ans)  # 7
	```
	この例では2品とも選べるので7。Wを4にすると答えは4になる。
	品物番号は0始まり。重さ・価値は0以上の整数、Wも0以上の整数を前提とする。何も選ばないことも許す。品物が空、または1個も入らない場合の答えは0。
## 3. 使う場面 {toggle="true"}
	- 各品物について「選ぶ／選ばない」を決める。
	- 重さ・費用の合計に上限があり、価値・利益を最大化したい。
	- 同じ品物を複数回は使えない。
	**Wが小さければ重さ版、価値の合計が小さければ価値版。** 品物数Nとの積が時間・メモリ制限に収まるかで選ぶ。両方が大きい場合は、この2種類のDPが適するとは限らない。
## 4. 注意事項 {toggle="true"}
	- このテンプレは「重さW以下」。容量を使い切る必要はない。
	- 重さ版の初期値は全て0。価値版は作れない状態を `INF` にし、`dp[0][0] = 0` だけ設定する。
	- 価値版の答えは **重さがW以下になる最大の価値k**。`max(dp[N])` ではない。
	- どちらも前の行 `dp[i]` を参照する。今の行から選ぶと、同じ品物を繰り返し使ってしまう可能性がある。
	- 「重さちょうどW」が必要な場合は、そのまま使わない。重さ版の初期行を `dp[0][0] = 0`、他を `-INF` に変え、最後に到達不能も確認する。
	- 同じ品物を何回でも使える問題、選んだ品物の復元には、別の処理が必要。
	- このページは2次元DP。省メモリの1次元DPへ変更するときは、更新順にも注意する。
## 5. 具体的な問題への適用例 {toggle="true"}
	### EDPC D — Knapsack 1 {toggle="true"}
		[問題ページ](https://atcoder.jp/contests/dp/tasks/dp_d)
		N ≤ 100、W ≤ 100000。重さを添字にする版を使う。入力は1行目が `N W`、続くN行が `重さ 価値`。
		以下は共通テンプレートの `main()` と末尾の呼び出し部分を置き換える例。setupはそのまま使う。
		```python
def main():
    N, W = map(int, input().split())
    items = [tuple(map(int, input().split())) for _ in range(N)]

    # dp[i][c]: 先頭i個から選び、重さc以下での価値の最大値
    dp = [[0] * (W + 1) for _ in range(N + 1)]

    for i, (weight, value) in enumerate(items):
        for c in range(W + 1):
            dp[i + 1][c] = dp[i][c]
            if c >= weight:
                dp[i + 1][c] = max(
                    dp[i + 1][c],
                    dp[i][c - weight] + value
                )

    print(dp[N][W])


if __name__ == "__main__":
    main()
		```
		2次元の表は最大約1000万マスになる。Pythonではメモリ使用量にも注意する。
	### EDPC E — Knapsack 2 {toggle="true"}
		[問題ページ](https://atcoder.jp/contests/dp/tasks/dp_e)
		N ≤ 100、W ≤ 10⁹、各価値 ≤ 1000。Wを添字にするのは大きすぎるため、合計が最大10万の価値を添字にする。
		以下は共通テンプレートの `main()` と末尾の呼び出し部分を置き換える例。
		```python
def main():
    N, W = map(int, input().split())
    w = [0] * N
    v = [0] * N
    for i in range(N):
        w[i], v[i] = map(int, input().split())

    S = sum(v)
    INF = 10**18  # この問題の重さの合計上限10**11より大きい

    # dp[i][k]: 先頭i個で価値をちょうどkにする最小重量
    dp = [[INF] * (S + 1) for _ in range(N + 1)]
    dp[0][0] = 0

    for i in range(N):
        for k in range(S + 1):
            dp[i + 1][k] = dp[i][k]  # 選ばない
            if k >= v[i]:           # 選ぶ
                dp[i + 1][k] = min(
                    dp[i + 1][k],
                    dp[i][k - v[i]] + w[i]
                )

    for k in range(S, -1, -1):
        if dp[N][k] <= W:
            print(k)
            return


if __name__ == "__main__":
    main()
		```
		この例の `INF = 10**18` は、問題の重さの合計上限 `10**11` より大きい値。汎用テンプレでは共通の `INF = float('inf')` を使っている。
		**以前のミス：****`10 * 18`**** は180。10の18乗は ****`10**18`****。**
		```plain text
1 200
200 10
		```
		この入力の正解は10。到達不能を180にすると、容量200以下と誤判定してしまう。特に `1000 * N` まで列を用意したコードでは、作れない価値1000まで選べる扱いになる。
## 6. 計算量 {toggle="true"}
	品物数をN、容量をW、価値の合計をVとする。
	- 重さ版：時間O(NW)、メモリO(NW)。
	- 価値版：時間O(NV)、メモリO(NV)。
	- 0も含めて厳密に表すと、重さ版の表は `(N + 1) × (W + 1)`、価値版は `(N + 1) × (V + 1)` マス。
	Pythonではリストと整数のメモリも必要。1次元DPならメモリをO(W)またはO(V)に減らせるが、このページのコードは2次元版。
## 7. よくあるミス {toggle="true"}
	- `items` の重さと価値を逆に入れる。
	- 「以下」と「ちょうど」を混ぜて初期値を決める。
	- 価値版を全て0で初期化し、作れない価値まで重さ0で作れる扱いにする。
	- `c >= weight` や `k >= value` を確認せず、負の添字を参照する。Pythonの負の添字は末尾からの参照になる。
	- 重さ版で `c == weight` のときしか選ばない。容量に余裕があっても選べる。
	- 前の行ではなく、今の行から値を取って同じ品物を再利用してしまう。
	- `[[0] * (W + 1)] * (N + 1)` と書いて、全行で同じリストを共有する。
	- `range(1, N)` で品物0を飛ばす。
	- 価値版で最小重量を出力する。求める答えは最大価値。
	確認する例：品物1個、容量と重さが一致、容量に余裕がある、1個も入らない、同じ重さの品物が複数ある場合。
