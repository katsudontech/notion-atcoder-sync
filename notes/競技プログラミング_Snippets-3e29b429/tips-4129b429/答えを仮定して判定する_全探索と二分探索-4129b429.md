# 答えを仮定して判定する｜全探索と二分探索

Source: https://www.notion.so/4129b4299e6180ada863fbb082d22f7f

---

<callout icon="💡" color="yellow_bg">
	最適な答えを直接探すのが難しいとき、\*\*「答えを x と仮定して、条件を満たせるか？」\*\*という Yes/No の判定問題に言い換える。
</callout>
## 発想の流れ
1. 答えの候補 `x` を決める
2. `check(x)` で実現可能か判定する
3. 候補が少なければ**全探索**、判定に**単調性**があれば**二分探索**で高速化する
## 例：典型90 001「Yokan Party」
求めるもの：**切ったピースの最短の長さを最大化**する。
→ 言い換え：**「全ピースを x cm 以上にして、K+1 個にできるか？」**
判定は貪欲法。左から見て、直前の切れ目から x cm 以上離れたらすぐ切る。早く切るほど右側の余裕が増えるため、条件を満たすピース数を最大化できる。
```python
def check(x):
    prev, cnt = 0, 0
    for a in A + [L]:  # 右端も含める
        if a - prev >= x:
            cnt += 1
            prev = a
    return cnt >= K + 1
```
- **全探索**：`x = 1, 2, ..., L` をすべて判定 → `O(NL)`
- **答えで二分探索**：小さい x は True、大きい x は False。**True の最大値**を探す → `O(N log L)`
```python
lo, hi = 0, L + 1  # True側 / False側
while hi - lo > 1:
    mid = (lo + hi) // 2
    if check(mid):
        lo = mid
    else:
        hi = mid
print(lo)
```
## 二分探索が使える条件
- 答えの候補を数値で表せる
- `check(x)` を効率よく計算できる
- **単調性がある**：例 `True True True False False`。この境界を探せる
「最小値の最大化」「最大値の最小化」は二分探索を疑うヒント。ただし**最大・最小という言葉だけでは決まらない**。単調性がなければ、候補全探索やDPなど別の方法を考える。
