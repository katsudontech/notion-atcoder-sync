## コピペ用コード
文字列・整数列のどちらにも使える。返り値は `[値, 連続個数]` を並べたリスト。
```python
def rle(seq):
    runs = []
    for x in seq:
        if runs and runs[-1][0] == x:
            runs[-1][1] += 1
        else:
            runs.append([x, 1])
    return runs
```
## 使い方
### 文字列
```python
S = "aaabbcaa"
runs = rle(S)
print(runs)
# [['a', 3], ['b', 2], ['c', 1], ['a', 2]]

for value, count in runs:
    print(value, count)
# a 3
# b 2
# c 1
# a 2
```
**隣り合う同じ値だけを、ひとつのかたまりにまとめる。** 離れた場所にある同じ値は別グループになる。
### 整数列
```python
A = [1, 1, 2, 2, 2, 1]
runs = rle(A)
# [[1, 2], [2, 3], [1, 1]]
```
### よく使う取り出し方
```python
runs = rle(S)

values = [value for value, count in runs]  # 各グループの値
counts = [count for value, count in runs]  # 各グループの長さ
group_count = len(runs)                   # グループ数
longest = max(counts, default=0)           # 最長の連続長（空なら0）
```
## 注意点・計算量
- **Counterとは別物。** Counterは位置に関係なく出現回数を合計する。ランレングス圧縮は順序と連続する区間を残す。
- **ソートしない。** ソートすると元の並びの連続関係が変わってしまう。
- 空文字列・空リストなら返り値は `[]`。上のコードは空入力にも対応している。
- 返り値の各要素はリスト。`runs[i][0]` が値、`runs[i][1]` が連続個数。
- 圧縮後の添字は「何番目のグループか」を表す。元の文字列・配列の添字とは異なる。
- 入力の長さをN、グループ数をMとすると、時間計算量は **O(N)**、返り値の領域は **O(M)**。Mは最大N。
- すべての隣接要素が異なればグループ数はNのまま。Pythonでは管理用オブジェクトもあるため、必ずメモリが減るわけではない。
## どういう問題で使う？
**要素を1個ずつ見る代わりに、同じ値のかたまり単位で考えたいとき。**
- 同じ文字・数字が連続する最大の長さを求める。
- 同じ値の連続区間の個数を数える。
- 隣り合うグループの長さを使って計算する。
- 文字の繰り返し回数に注目して、2つの文字列を比較する。
### 例：すべて同じ文字からなる連続部分文字列の個数
長さ `count` のグループ内には、条件を満たす部分文字列が `count * (count + 1) // 2` 個ある。位置の異なるものを別々に数える。
```python
S = "aaabb"
ans = sum(count * (count + 1) // 2 for _, count in rle(S))
print(ans)  # 6 + 3 = 9
```
長さ3の `aaa` なら、長さ1が3個、長さ2が2個、長さ3が1個で合計6個。異なるグループをまたぐと別の文字が入るので、グループごとに足せばよい。
## 元の区間の位置も必要な場合
基本コードの結果から連続個数を足していけば、各グループの区間を復元できる。0-indexedの半開区間 `[left, right)`。
```python
S = "aaabbcaa"
left = 0
for value, count in rle(S):
    right = left + count
    print(value, count, left, right)
    left = right
# a 3 0 3
# b 2 3 5
# c 1 5 6
# a 2 6 8
```
グループに含まれる元の添字は `left` から `right - 1` まで。
## 元に戻す場合
### 文字列
```python
runs = rle("aaabbcaa")
S = "".join(value * count for value, count in runs)
```
### 整数列
```python
runs = rle([1, 1, 2, 2, 2, 1])
A = [value for value, count in runs for _ in range(count)]
```
復元すると元の長さNぶんの時間・領域が必要。最初から巨大な連続個数が与えられる問題では、展開せずグループ単位で処理する。
