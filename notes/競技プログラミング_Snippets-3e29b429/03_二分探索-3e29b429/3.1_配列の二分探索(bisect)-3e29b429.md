## 本番用：bisect早見表
**left＝同じ値の手前 ／ right＝同じ値の後ろ**
```plain text
x = 4
left  : [2 | 4, 4, 7]  → 1
right : [2, 4, 4 | 7]  → 3

left  : [ < x | >= x ]
right : [ <= x | > x ]
```

# Aは昇順

```python

count = bisect_right(A, R) - bisect_left(A, L)
```
### ミス防止
- **先に条件を \>= / \> / \< / \<= で書く。**
- 戻り値は「値」ではなく「位置」。0〜len(A)。
- 該当なしに注意。**A\[-1\]は末尾を返す！**
- Aは昇順。1回 O(log N)。
- xがなければ、leftとrightは同じ位置。
- 変数名がrightでも、bisect_rightとは限らない。
### 今回の問題：組の終了位置から探す {toggle="true"}
	```python
end = [0, 1, 3, 6, 10]

# 位置pを含む組：終了位置 >= p の最初
k = bisect_left(end, p)  # 第k組（1始まり）
	```
	p=3は第2組の末尾。leftなら2、rightだと3になって次の組へ進む。
	**LもRも「終了位置 \>= その位置」を探すので、両方left。**<br>元のコードでは「前にある組の数」が必要なので、さらに1を引く。
---
## 実戦テンプレ {toggle="true"}
	```python
A.sort()
left = bisect_left(A, x)    # x以上が初めて現れる位置
right = bisect_right(A, x)  # xより大きい値が初めて現れる位置
count = right - left
	```
## 注意事項 {toggle="true"}
	- 対象配列はソート済みであること
	- 戻り値は要素ではなく挿入位置
## 計算量 {toggle="true"}
	- 1回：O(log N)
## よくあるミス {toggle="true"}
	- ソートを忘れる
	- leftとrightの境界を混同する
