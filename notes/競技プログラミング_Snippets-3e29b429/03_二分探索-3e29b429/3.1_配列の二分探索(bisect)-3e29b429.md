# 3.1 配列の二分探索（bisect）

Source: https://www.notion.so/3e29b4299e618133a241d2313d6d466b

---

## 実戦テンプレ {toggle="true"}
	```python
A.sort()
left = bisect_left(A, x)    # x以上が初めて現れる位置
right = bisect_right(A, x)  # xより大きい値が初めて現れる位置
count = right - left
	```
## 注意事項 {toggle="true"}
	- 対象配列はソート済みであること
	- 戻り値は要素ではなく挿入位置
## 計算量 {toggle="true"}
	- 1回：O(log N)
## よくあるミス {toggle="true"}
	- ソートを忘れる
	- leftとrightの境界を混同する
