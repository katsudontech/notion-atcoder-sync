## 実戦テンプレ
```python
# ngは条件を満たさず、okは条件を満たす
ng = -1
ok = 10**18
while ok - ng > 1:
    mid = (ok + ng) // 2
    if is_ok(mid):
        ok = mid
    else:
        ng = mid
print(ok)
```
## 使う場面
- 真偽が境界を境に一方向へ切り替わる
- 最小値や最大値を直接求めにくい
## 注意事項
- is_ok(x) の単調性を確認する
- ngとokの意味をコメントで固定する
## よくあるミス
- 初期値の真偽を保証しない
- 最大化問題に最小化用の更新を使う
