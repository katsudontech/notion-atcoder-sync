## 実戦テンプレ {toggle="true"}
	**最小値を求める：False → True の境界**
	例：時間を増やすほど達成しやすいとき、達成できる最小の時間を探す。
	```python
# ngは条件を満たさず、okは条件を満たす
ng = -1
ok = 10**18
while ok - ng > 1:
    mid = (ok + ng) // 2
    if is_ok(mid):
        ok = mid
    else:
        ng = mid
print(ok)
	```
	**最大値を求める：True → False の境界**
	例：間隔を広げるほど達成しにくいとき、確保できる最大の間隔を探す。
	```python
# okは条件を満たし、ngは条件を満たさない
ok = 0
ng = 10**18
while ng - ok > 1:
    mid = (ok + ng) // 2
    if is_ok(mid):
        ok = mid
    else:
        ng = mid
print(ok)
	```
	どちらも `is_ok(mid)` が True なら `ok = mid`。変わるのは真偽の並ぶ向きと、ok・ng の左右。<br>初期値は問題に合わせる（上の例は各コメントの真偽を保証できる場合）。解なしは別途処理し、0 だけ False にするなど単調性を崩さない。
## 使う場面 {toggle="true"}
	- 真偽が境界を境に一方向へ切り替わる
	- 最小値や最大値を直接求めにくい
## 注意事項 {toggle="true"}
	- is_ok(x) の単調性を確認する
	- ngとokの意味をコメントで固定する
## よくあるミス {toggle="true"}
	- 初期値の真偽を保証しない
	- 最大化問題に最小化用の更新を使う
