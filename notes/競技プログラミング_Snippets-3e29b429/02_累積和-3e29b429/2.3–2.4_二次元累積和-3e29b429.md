## 実戦テンプレ
```python
S = [[0] * (W + 1) for _ in range(H + 1)]
for i in range(H):
    for j in range(W):
        S[i + 1][j + 1] = A[i][j] + S[i][j + 1] + S[i + 1][j] - S[i][j]

# 半開矩形 [x1, x2) × [y1, y2)
ans = S[x2][y2] - S[x1][y2] - S[x2][y1] + S[x1][y1]
```
## 注意事項
- 足した領域の重複を最後に1回引く
- 縦横とも先頭に0の番兵を置く
## 計算量
- 前処理：O(HW)
- 1クエリ：O(1)
## よくあるミス
- \[\[0\] * (W + 1)\] * (H + 1) と書いて行を共有する
- xとy、行と列を逆にする
