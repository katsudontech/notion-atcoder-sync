# 2.1–2.2 一次元累積和

Source: https://www.notion.so/3e29b4299e618103b4ffd8002c1c5488

---

## 実戦テンプレ
```python
S = [0] * (N + 1)
for i in range(N):
    S[i + 1] = S[i] + A[i]

# 半開区間 [l, r) の合計
ans = S[r] - S[l]
```
## 使う場面
- 区間和を何度も求める
- 0〜1の配列にして、条件を満たす個数を区間ごとに数える
## 注意事項
- S\[i\] は A\[0:i\] の合計
- iが、足す個数って覚えると良い
- だから、s\[i\]にA\[i\]は含まれない
- 問題の閉区間を0-indexedの半開区間へ直す
## 計算量
- 前処理：O(N)
- 1クエリ：O(1)
## よくあるミス
- 先頭の0を用意しない
- S\[r\] - S\[l\] と S\[r + 1\] - S\[l\] を混同する
