<callout icon="💡" color="blue_bg">
	C++の `std::set` / `std::multiset` に近い操作をPythonで行うための実戦用メモ。AtCoderでは `sortedcontainers` が利用できる。
</callout>
## 結論
- **重複なしの順序付き集合**：`SortedSet`
- **重複ありの順序付き集合**：`SortedList`
- 順序が不要で、追加・削除・存在判定だけなら組み込みの `set` を使う
Python標準の `set` は要素を順序どおりに保持しない。そのため、最小値・最大値、`lower_bound`、直前・直後の要素が必要な問題では `SortedSet` などを使う。
## `SortedSet`：C++の `std::set` 相当
```python
from sortedcontainers import SortedSet

S = SortedSet()

S.add(10)
S.add(30)
S.add(20)
S.add(10)       # 重複する値は追加されない

print(S)        # SortedSet([10, 20, 30])
print(20 in S)  # True
print(S[0])     # 最小値
print(S[-1])    # 最大値

S.discard(20)   # 存在しなくてもエラーにならない
```

## 境界探索の4パターン
### `x` 以上の最小値
```python
i = S.bisect_left(x)
ans = S[i] if i < len(S) else None
```
### `x` より大きい最小値
```python
i = S.bisect_right(x)
ans = S[i] if i < len(S) else None
```
### `x` 未満の最大値
```python
i = S.bisect_left(x)
ans = S[i - 1] if i > 0 else None
```
### `x` 以下の最大値
```python
i = S.bisect_right(x)
ans = S[i - 1] if i > 0 else None
```
<callout icon="⚠️" color="yellow_bg">
	`bisect_left` / `bisect_right` が返すのは**値ではなく添字**。`S[i]` を読む前に、`0 <= i < len(S)` の範囲確認をする。
</callout>
## テンプレート：前後の値を取得する
```python
from sortedcontainers import SortedSet

def ge(S, x):
    """x以上の最小値。なければNone"""
    i = S.bisect_left(x)
    return S[i] if i < len(S) else None

def gt(S, x):
    """xより大きい最小値。なければNone"""
    i = S.bisect_right(x)
    return S[i] if i < len(S) else None

def lt(S, x):
    """x未満の最大値。なければNone"""
    i = S.bisect_left(x)
    return S[i - 1] if i > 0 else None

def le(S, x):
    """x以下の最大値。なければNone"""
    i = S.bisect_right(x)
    return S[i - 1] if i > 0 else None
```
## 適用例：最も近い値を求める
`S` に値を追加しながら、クエリ `x` に最も近い登録済みの値との差を求める。
```python
from sortedcontainers import SortedSet

S = SortedSet()

def min_distance(S, x):
    ans = float("inf")
    i = S.bisect_left(x)

    if i < len(S):
        ans = min(ans, abs(S[i] - x))
    if i > 0:
        ans = min(ans, abs(S[i - 1] - x))

    return ans

S.add(3)
S.add(10)
S.add(20)

print(min_distance(S, 13))  # 3
```
`x` に最も近い候補は、挿入位置の要素と、その1つ前の要素だけ調べればよい。
## `SortedList`：C++の `multiset` 相当
`SortedSet` は同じ値を1個しか保持できない。重複を残したい場合は `SortedList` を使う。
```python
from sortedcontainers import SortedList

S = SortedList([1, 1, 2, 3])
S.add(1)

print(S)          # SortedList([1, 1, 1, 2, 3])
print(S.count(1)) # 3

S.remove(1)       # 1個だけ削除
print(S)          # SortedList([1, 1, 2, 3])
```

## 注意点
- `S[0]`、`S[-1]` は空集合では `IndexError` になる
- `discard(x)` は `x` がなくても何もしないが、`remove(x)` はエラーになる
- `SortedSet` は重複を消す。重複が意味を持つ問題では `SortedList` を使う
- `sortedcontainers` はPython標準ライブラリではない。AtCoder以外では利用可能か確認する
- ローカル環境で未導入なら `pip install sortedcontainers` を実行する
- テストケース試すツールがうまく使えないかも
