# 8.10 順序付き集合（SortedSet / SortedList）

Source: https://www.notion.so/3e29b4299e6181b1873dd6c1c1b91c02

**値を追加・削除しながら、昇順で管理したいときに使う。**<br>重複を残すなら `SortedList`、同じ値を1個にまとめるなら `SortedSet`。
## 本番用テンプレ・基本操作 {toggle="true"}
	```python
from sortedcontainers import SortedList, SortedSet

S = SortedList()  # 重複あり。重複なしなら SortedSet()
S.add(20)
S.add(10)
S.add(20)         # SortedList: [10, 20, 20]

S.discard(20)    # 20を1個だけ削除。なければ何もしない

if S:
    minimum = S[0]
    maximum = S[-1]
	```

	```python
# 例：x以下の最大値

ans = S[i] if 0 <= i < len(S) else None
	```
	表から添字の式を選び、同じ範囲チェックで使う。`None` は該当なし。問題に合わせて処理する。

## 注意事項・よくあるミス {toggle="true"}
	- **重複が答えに影響するなら SortedList。** 累積和なども同じ値になることがある。
	- `S[-1]` は末尾。前の値が存在しないときの添字 `-1` を、そのまま使わない。
	- 空のときに `S[0]`・`S[-1]`・`pop()` を使うとエラー。
	- `remove(x)` はxがないとエラー。`discard(x)` は何もしない。SortedListではどちらも1個だけ削除する。
	- 追加は `add(x)`。通常のリストのように `append(x)` や `S[i] = x` は使わない。
	- 順序は追加した順ではなく、値の昇順。タプルは先頭から辞書順で比較される。

## AtCoder・ローカル・CPHで使う {toggle="true"}
	**Python標準ライブラリではないが、AtCoderのCPython・PyPyには導入済み。** 提出コードには `from sortedcontainers import ...` を書けばよい。
	[AtCoder公式：使用できる言語とライブラリ](https://img.atcoder.jp/file/language-update/2025-10/language-list.html)
	ローカルで未導入なら、ターミナルで実行する。以下は今回の環境で使う `python3` の例。
	```bash
python3 -m pip install sortedcontainers
	```
	このコマンドは提出コードには書かない。
	**CPHは、実行に使うPythonに導入されていれば利用できる。今回の環境ではCPHからの動作確認済み。**
	別の環境で確認するときは、以下をCPHで実行する。
	```python
import sys
print(sys.executable)  # CPHが使うPython

from sortedcontainers import SortedList
print(SortedList([3, 1, 2]))  # SortedList([1, 2, 3])
	```
	`ModuleNotFoundError` が出る場合は、表示されたPythonにインストールする。CPHの実行コマンドはVS Code設定の `cph.language.python.Command` で確認できる。
	実行は成功するのにエディタの警告が残る場合は、「Python: インタープリターを選択」で同じPythonを選ぶ。
