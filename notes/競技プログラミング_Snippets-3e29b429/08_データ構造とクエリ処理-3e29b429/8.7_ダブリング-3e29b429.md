## 1. テンプレ {toggle="true"}
	「各場所の移動先が1つに決まっている」ときに、K回移動した後の位置を求める。追加のimportは不要。番号は0-indexedで扱う。
	### 基本版：到着位置だけ求める {toggle="true"}
		```python
def build_doubling(nxt, max_k):
    """nxt[v]: vから1回移動した先。0-indexed。
    max_k: 問い合わせる移動回数の最大値（0以上）。
    戻り値 jump[j][v]: vから2**j回移動した先。
    """
    if max_k < 0:
        raise ValueError("max_k must be non-negative")

    n = len(nxt)
    log = max(1, max_k.bit_length())
    jump = [list(nxt)]

    for _ in range(1, log):
        prev = jump[-1]
        jump.append([prev[prev[v]] for v in range(n)])

    return jump


def kth_next(jump, start, k):
    """startからk回移動した先を返す。k=0ならstart。"""
    if k < 0 or k.bit_length() > len(jump):
        raise ValueError("k is negative or exceeds the table capacity")

    v = start
    bit = 0
    while k:
        if k & 1:
            v = jump[bit][v]
        k >>= 1
        bit += 1

    return v
		```
	### 必要なときだけ：移動中の合計も求める {toggle="true"}
		基本版とは独立して使える2関数。`weight[v]` は「場所vから1回出発するときに加算する値」。
		```python
def build_doubling_sum(nxt, weight, max_k):
    """weight[v]: vから1回出発するときに得る値。
    戻り値: jump（移動先の表）, gain（合計の表）。
    """
    if max_k < 0:
        raise ValueError("max_k must be non-negative")

    n = len(nxt)
    log = max(1, max_k.bit_length())
    jump = [list(nxt)]
    gain = [list(weight)]

    for _ in range(1, log):
        prev_jump = jump[-1]
        prev_gain = gain[-1]

        jump.append([prev_jump[prev_jump[v]] for v in range(n)])
        gain.append([
            prev_gain[v] + prev_gain[prev_jump[v]]
            for v in range(n)
        ])

    return jump, gain


def jump_with_sum(jump, gain, start, k):
    """(k回移動後の位置, k回の移動で得た合計)を返す。"""
    if k < 0 or k.bit_length() > len(jump):
        raise ValueError("k is negative or exceeds the table capacity")

    v = start
    total = 0
    bit = 0

    while k:
        if k & 1:
            # 必ず移動前のvで合計を取得する
            total += gain[bit][v]
            v = jump[bit][v]
        k >>= 1
        bit += 1

    return v, total
		```
## 2. それの使い方 {toggle="true"}
	### 基本版 {toggle="true"}
		まず `nxt` と `max_k` を用意する。
		- `nxt[v]`：場所vから1回移動した先の番号。
		- `max_k`：問い合わせる移動回数の最大値。
		- `start`：開始位置。
		- `k`：今回移動する回数。
		`jump = build_doubling(nxt, max_k)` で表を1回だけ作る。その表を `kth_next(jump, start, k)` に渡すと、到着位置の番号が返る。`jump` は自分で編集せず、そのまま使い回せばよい。
		```python
nxt = [1, 2, 3, 4, 0]  # 0→1→2→3→4→0 のサイクル
jump = build_doubling(nxt, 13)

print(kth_next(jump, 0, 13))  # 3
print(kth_next(jump, 0, 0))   # 0
print(kth_next(jump, 2, 4))   # 1
		```
		`nxt = [1, 2, 3, 4, 0]` は、`0 → 1 → 2 → 3 → 4 → 0` と移動するという意味。`k = 0` なら開始位置がそのまま返る。
	### 入力から使う例：鉄則 A57 {toggle="true"}
		入力は、1行目に `N Q`、2行目にN個の移動先、その後Q行に `開始位置 移動回数`。場所の番号は入力・出力ともに1始まり。
		基本版の2関数を用意し、次のコードを `main()` の中に1段インデントして置く。
		```python
N, Q = map(int, input().split())
nxt = [int(x) - 1 for x in input().split()]
queries = [tuple(map(int, input().split())) for _ in range(Q)]

max_k = max((k for _, k in queries), default=0)
jump = build_doubling(nxt, max_k)

answers = []
for start, k in queries:
    goal = kth_next(jump, start - 1, k)
    answers.append(str(goal + 1))

print("\n".join(answers))
		```
		移動先と開始位置は1を引いて内部の番号に直し、出力するときに1を足す。
	### 合計付き版 {toggle="true"}
		`jump, gain = build_doubling_sum(nxt, weight, max_k)` で表を作り、`jump_with_sum(jump, gain, start, k)` を呼ぶ。戻り値は **（到着位置, 合計）**。
		```python
nxt = [1, 2, 0]
weight = [10, 20, 30]
jump, gain = build_doubling_sum(nxt, weight, 4)

print(jump_with_sum(jump, gain, 0, 4))  # (1, 70)
print(jump_with_sum(jump, gain, 0, 0))  # (0, 0)
		```
		この例の4回の移動は `0 → 1 → 2 → 0 → 1`。出発した場所の値を足すので、合計は `10 + 20 + 30 + 10 = 70`。最後の到着地点の値は追加で足さない。
		`k = 0` なら `(start, 0)`。到着する場所の値を毎回足したい場合は、`weight = [value[nxt[v]] for v in range(len(nxt))]` を渡す。
	### 合計付き版の適用例：ABC241 E {toggle="true"}
		`X = 0` から `X += A[X % N]` をK回行う場合。場所の番号を `X % N` として、次のように使う。
		```python
# A, Kが与えられ、X=0から始める場合
N = len(A)
nxt = [(v + A[v]) % N for v in range(N)]

jump, gain = build_doubling_sum(nxt, A, K)
remainder, answer = jump_with_sum(jump, gain, 0, K)
print(answer)
		```
		答えは `answer`。余りにするのは場所の番号だけで、合計そのものはNで割らない。
	### 木でK個上の祖先を求める {toggle="true"}
		基本版の2関数と併用する。`parent[v]` に親の番号、親がなければ `-1` を用意する。
		```python
# 根0。parent[v]はvの親、親なしは-1。
parent = [-1, 0, 0, 1, 1]
N = len(parent)
sentinel = N

# -1を番兵Nへ置換し、番兵は自分自身へ移動する
nxt = [p if p != -1 else sentinel for p in parent] + [sentinel]
jump = build_doubling(nxt, 3)

def kth_ancestor(v, k):
    goal = kth_next(jump, v, k)
    return -1 if goal == sentinel else goal

print(kth_ancestor(4, 2))  # 0
print(kth_ancestor(4, 3))  # -1
		```
		戻り値は祖先の番号。存在しなければ `-1`。この例は最大3個上までを想定しているため、別の回数を使うときは前計算の `3` を最大Kに変更する。
## 3. 使う場面 {toggle="true"}
	- テレポートなど、移動先が決まっている操作を大量に繰り返す。
	- 同じ移動規則で、開始位置や移動回数が異なる問い合わせが多い。
	- 移動後の位置に加えて、途中の得点やコストの合計も知りたい。
	- 根付き木で、K個上の祖先を求めたい。
	複数の移動先から最短経路を選ぶ問題には、BFSやダイクストラ法を使う。開始位置が1つで問い合わせも1回なら、サイクル検出も候補になる。
## 4. 注意事項 {toggle="true"}
	- `nxt` の長さをNとし、Nは1以上。すべての移動先を `0 <= nxt[v] < N` にする。
	- 開始位置も `0 <= start < N`、移動回数は `0 <= k <= max_k` を前提にする。
	- 前計算には **状態数Nではなく、最大の移動回数K** を渡す。たとえば最大Kが `10**18` なら60段の表になる。
	- 表の容量を超えるKや負のKを問い合わせると、このテンプレートは `ValueError` を出す。
	- サイクルや自己ループがあっても使える。
	- 移動先や重みは固定が前提。変更後は古い表を使わず、作り直す。
	- 合計付き版では `len(weight) == len(nxt)` にする。負の重みも扱える。
	- 行き先なしの `-1` を直接渡さない。祖先検索の例では、行き先なしを表す追加の場所Nを用意している。
	- 合計付き版でも追加の場所を使うなら、その場所の重みは0にする。
## 5. 計算量 {toggle="true"}
	状態数をN、問い合わせ数をQ、`B = max(1, max_k.bit_length())` とする。
	- 前計算：O(NB)。
	- 1回の問い合わせ：O(B)以内。Kが0ならO(1)。
	- 前計算とQ回の問い合わせ：O((N + Q)B)。
	- 前計算表のメモリ：O(NB)。基本版は表1つ、合計付き版は表2つ。
	- 入力例のようにクエリと出力を保存する場合は、追加でO(Q)のメモリが必要。
	Nが20万、Bが60なら、表1つで1200万要素になる。Pythonではメモリ使用量に注意し、最大Kを必要以上に大きくしない。合計付き版の計算量は、整数の加算をO(1)とみなしたもの。非常に大きい整数では、その桁数の影響も受ける。
## 6. よくあるミス {toggle="true"}
	- `nxt[v]` に移動先の番号ではなく、移動距離を入れてしまう。
	- 入力の1始まりと、内部の0始まりを混ぜる。
	- `build_doubling(nxt, N)` としてしまう。第2引数は最大の移動回数。
	- 問い合わせのたびに表を作り直す。同じ移動規則なら1回作って共有する。
	- `-1` を行き先に入れる。Pythonでは配列の末尾を指すため、誤った場所へ進む。
	- 合計付き版で、出発地点の値と到着地点の値を混同する。
	- 同じ場所を再訪したときの値を一度しか数えない。このテンプレートでは通るたびに加算する。
	- 到着位置だけでなく、途中の全経路も同じ計算量で取得できると思う。K回分の経路を出力するにはO(K)が必要。
