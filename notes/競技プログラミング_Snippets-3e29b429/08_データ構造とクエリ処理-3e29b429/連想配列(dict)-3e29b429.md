## dict：キーと値を対応させる
```python
d = {}
d["apple"] = 3               # 追加・上書き
print(d["apple"])           # 3
print("apple" in d)         # キーがあるか
print(d.get("banana", 0))   # なければ0（追加はしない）

for key, value in d.items():
    print(key, value)

del d["apple"]             # 削除
```
存在しないキーを `d[key]` で読むとエラー。
## defaultdict：ないキーの初期値を自動で作る
```python
from collections import defaultdict

cnt = defaultdict(int)     # 初期値0
cnt["apple"] += 1          # 未登録でもOK

groups = defaultdict(list) # 初期値[]
groups["A"].append(10)
groups["A"].append(20)     # groups["A"] は [10, 20]
```
**普通の対応表は dict、回数を足すなら defaultdict(int)、分類して集めるなら defaultdict(list)。**<br>`d[key]` で未登録のキーを読むと、初期値が辞書に追加される。
