	ACL Python の `SegTree` を使い、要素の一点更新と区間最小値を高速に処理する。クエリ区間は左端を含み、右端を含まない半開区間。

## 実戦テンプレ
```python
from atcoder.segtree import SegTree


INF = float("inf")

# op：区間の情報を結合する演算
# e ：opの単位元。min(INF, x) == x
def op(a, b):
    return min(a, b)


A = list(map(int, input().split()))
seg = SegTree(op, INF, A)
```
短く書く場合は次でもよい。
```python
seg = SegTree(min, float("inf"), A)
```
## 基本操作
```python
# A[p] を x に変更
seg.set(p, x)

# 現在の A[p] を取得
value = seg.get(p)

# 半開区間 [l, r) の最小値
minimum = seg.prod(l, r)

# 全要素の最小値
minimum_all = seg.all_prod()
```
## 長さNの初期配列を単位元で作る
最初から配列を持っていない場合は、第三引数に長さを渡せる。
```python
seg = SegTree(min, float("inf"), N)
```
この場合、すべての要素が最初は `INF` になる。
## 例
```python
A = [5, 2, 8, 6, 1]
seg = SegTree(min, float("inf"), A)

print(seg.prod(1, 4))  # min(2, 8, 6) = 2

seg.set(1, 7)          # A[1]を2から7へ変更

print(seg.prod(1, 4))  # min(7, 8, 6) = 6
print(seg.get(1))      # 7
print(seg.all_prod())  # 1
```
## 各引数の意味
- `op(a, b)`：左右の区間情報を結合する関数。RMQでは `min`
- `e`：何と結合しても結果を変えない単位元。RMQでは `INF`
- 第三引数：初期配列、または要素数 `N`
## 使う場面
- 配列の値を更新しながら区間最小値を何度も求める
- 全区間を毎回走査すると間に合わない
- クエリ数が多い
## 注意事項
- `prod(l, r)` は半開区間。添字 `r` の要素は含まれない
- `set(p, x)` は加算ではなく、値を `x` に置き換える
- `prod(l, l)` のような空区間では単位元 `INF` が返る
- `op` は結合順を変えても問題ない結合的な演算である必要がある
- 0-indexedで扱う
## 計算量
- 構築：O(N)
- `set`：O(log N)
- `get`：O(1)
- `prod`：O(log N)
- `all_prod`：O(1)
## よくあるミス
- 閉区間のつもりで `prod(l, r)` を呼び、右端を1つ落とす
- 一点加算のつもりで `seg.set(p, x)` を使う
- RMQの単位元を0にして、最小値が常に0になる
- 最大値を求めたいのに `min` を使う
