# 10.4 座標圧縮

Source: https://www.notion.so/4189b4299e618172b184f667622dc68b

---

## コピペ用コード {toggle="true"}
	値の大小関係を保ったまま、0から始まる連番に変換する。
	```python
def compress(A):
    values = sorted(set(A))
    index = {v: i for i, v in enumerate(values)}
    B = [index[a] for a in A]
    return B, values, index
	```
	返り値：
	- `B`：圧縮した配列
	- `values`：圧縮後の番号 → 元の値（リスト）
	- `index`：元の値 → 圧縮後の番号（辞書）
	座標圧縮するだけならBで十分なのかな<br>values, indexはザ圧前後をつなげるためのリスト
## 使い方 {toggle="true"}
	```python
A = [100, -5, 100, 20]
B, values, index = compress(A)

print(B)          # [2, 0, 2, 1]
print(values)     # [-5, 20, 100]
print(index[100]) # 2（元の値 → 番号）
print(values[2])  # 100（番号 → 元の値）
	```
## 使う場面 {toggle="true"}
	- 値が大きい・負の値があるが、配列の添字として扱いたい。
	- BITやセグメント木で、値ごとの個数・重みを管理したい。
	- **多分、値自体に意味はなくて値の順位だけに興味があって、かつ普通にやろうとするとMLEになるときに使うのかな**
## 注意点・計算量 {toggle="true"}
	- 同じ値は同じ番号になる。Bは元の配列の順序と重複を保持する。
	- 大小関係は保つが、差・距離は保たない。
	- 更新対象の値は事前にすべて集める。複数配列ならまとめて圧縮する。
	- 長さNの配列に対して、時間 O(N log N)、空間 O(N)。
