## ビットの基本演算 {toggle="true"}
	### 2進数とビットの位置 {toggle="true"}
		```python
x = 0b0101         # 2進数で0101 = 10進数で5
print(x)           # 5
print(bin(x))      # '0b101'
print(f"{x:04b}")  # '0101'（最低4桁で表示）
		```
		右端が0ビット目。その左が1ビット目、2ビット目…となる。
		```plain text
ビット位置：  3 2 1 0
5の2進数 ：  0 1 0 1
各桁の値 ：  8 4 2 1

5 = 4 + 1
		```
	### AND・OR・XOR・NOT {toggle="true"}

		```python
a, b = 5, 3
print(a & b)  # 1
print(a | b)  # 7
print(a ^ b)  # 6

print(a ^ a)  # 0：同じ値をXORすると消える
print(a ^ 0)  # 5：0とのXORでは変わらない
		```
		Pythonの整数は固定の4ビットなどではないため、`~x == -x - 1` になる。下位Nビットだけを反転するなら、使う範囲を限定する。
		```python
N = 4
full = (1 << N) - 1  # 1111
x = 0b0101

print((~x) & full)   # 10 = 1010
		```
	### 左シフト \<\<・右シフト \>\> {toggle="true"}
		非負整数x、0以上の整数kについて、左シフトは2のk乗倍、右シフトは2のk乗で割った商。
		```python
x = 5               # 0101

print(x << 1)       # 10：1010（2倍）
print(x << 2)       # 20：10100（4倍）
print(x >> 1)       # 2 ：0010（2で割った商）
print(x >> 2)       # 1 ：0001（4で割った商）

print(1 << 3)       # 8：3ビット目だけ1
print(1 << N)       # 2**N
		```
		`1 << i` は「iビット目だけが1の数」。ビット操作でよく使う。
	### iビット目を調べる・変更する {toggle="true"}
		iは右端から0-indexed。
		```python
mask = 0b0101
i = 2

# iビット目を0か1で取得
bit = (mask >> i) & 1   # 1

# iビット目が1か判定（どちらでもよい）
if (mask >> i) & 1:
    print("選ばれている")

if mask & (1 << i):
    print("選ばれている")

# 各行を単独で使う場合の操作
mask |= 1 << i         # iビット目を1にする
mask &= ~(1 << i)      # iビット目を0にする
mask ^= 1 << i         # iビット目を反転する
		```
		`mask & (1 << i)` は0または2のi乗。`(mask >> i) & 1` は0または1を返す。
	### 1の個数・全ビットが1の数 {toggle="true"}
		```python
mask = 0b10110

print(mask.bit_count())  # 3：1の個数
print(mask.bit_length()) # 5：2進数表現に必要な桁数

N = 5
full = (1 << N) - 1
print(bin(full))         # '0b11111'
		```
		選ぶ個数をK個に限定するなら、`mask.bit_count() == K` で判定できる。
## ビット全探索 {toggle="true"}
	### 考え方 {toggle="true"}
		N個の要素について「選ぶ・選ばない」をすべて試す。選び方は2のN乗通りで、`0` から `(1 << N) - 1` の整数に対応する。
		iビット目が1なら、`A[i]` を選ぶ。
		```plain text
A = [2, 3, 5]

mask   選ぶ要素
000    []          ← 何も選ばない
001    [2]
010    [3]
011    [2, 3]
100    [5]
101    [2, 5]
110    [3, 5]
111    [2, 3, 5]   ← 全部選ぶ
		```
		右端のビットが `A[0]` に対応する。
	### 基本テンプレ {toggle="true"}
		```python
A = [2, 3, 5]
N = len(A)

for mask in range(1 << N):
    selected = []

    for i in range(N):
        if (mask >> i) & 1:
            selected.append(A[i])

    # ここで、この選び方を調べる
    print(selected)
		```
		空集合も含む。空集合を除く場合は `range(1, 1 << N)` にする。
	### 例：合計がtargetになる選び方を数える {toggle="true"}
		値の合計だけ必要なら、選んだ要素のリストを作らず、その場で足す。
		```python
A = [2, 3, 5]
target = 5
N = len(A)

ans = 0

for mask in range(1 << N):
    total = 0

    for i in range(N):
        if (mask >> i) & 1:
            total += A[i]

    if total == target:
        ans += 1

print(ans)  # 2：[2, 3]と[5]
		```
		同じ値が複数あっても、添字が違えば別の要素として数える。`target == 0` の場合は、何も選ばない選び方も数える。
	### 使う場面・計算量 {toggle="true"}
		- 各要素について「選ぶ・選ばない」の2択がある
		- すべての部分集合を試して、条件を満たす個数や最大値・最小値を求める
		- Nが小さく、2のN乗通りを調べられる
		上のテンプレは、2のN乗通りのそれぞれでN要素を見るので **O(N × 2のN乗)**。
		N=20でも約105万通り、内側の判定は約2100万回になる。制限時間と、各選び方で行う処理の重さを確認する。
## 注意点・よくあるミス {toggle="true"}
	- `2 ^ N` は累乗ではなくXOR。2のN乗は `1 << N` または `2 ** N`。
	- `and / or / not` は論理演算。`& / | / ~` とは使い方が違う。
	- ビット位置は右端から数える。0ビット目が最下位。
	- `mask >> i` だけではiビット目を取り出せない。`& 1` を付ける。
	- `range(N)` ではN通りしか試せない。全探索は `range(1 << N)`。
	- `~mask` だけでNビットの反転になると思わない。
	- 部分集合の列挙なので、選んだ要素の並べ方までは列挙しない。
	- ビット位置やシフト量に負数は使わない。ここでのmaskは非負整数として扱う。
