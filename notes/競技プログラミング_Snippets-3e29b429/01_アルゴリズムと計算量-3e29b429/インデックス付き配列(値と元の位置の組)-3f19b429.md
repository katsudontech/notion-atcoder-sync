# インデックス付き配列（値と元の位置の組）

Source: https://www.notion.so/3f19b4299e6181d69c3ad35836502289

---

## コピペ用コード
配列から **(値, 元のインデックス)** の組を並べたリストを作る。インデックスは0-indexed。
```python
pairs = [(x, i) for i, x in enumerate(A)]
```
関数として使う場合：
```python
def with_index(A):
    return [(x, i) for i, x in enumerate(A)]
```
## 使い方
### 組のリストを作る
```python
A = [30, 10, 20]
pairs = with_index(A)
print(pairs)
# [(30, 0), (10, 1), (20, 2)]
```
`pairs` はリストで、各要素は `(値, インデックス)` のタプル。
```python
for value, index in pairs:
    print(value, index)
# 30 0
# 10 1
# 20 2
```
### 元の位置を残して値の昇順にソートする
```python
A = [30, 10, 20]
pairs = [(x, i) for i, x in enumerate(A)]
pairs.sort()
print(pairs)
# [(10, 1), (20, 2), (30, 0)]

for value, original_index in pairs:
    print(value, original_index)
```
タプルは先頭から比較されるため、**値の昇順、同じ値ならインデックスの昇順**になる。元の配列Aは変更されない。
### 1-indexedの番号を付ける
```python
A = [30, 10, 20]
pairs = [(x, i) for i, x in enumerate(A, start=1)]
# [(30, 1), (10, 2), (20, 3)]
```
問題で「何番目か」を1から数えて出力するときに便利。この場合、元の値は `A[i - 1]`。
## 注意点・計算量
- **enumerate自体の順番は (インデックス, 値)。** 内包表記の `(x, i)` で順番を入れ替えている。
- `list(enumerate(A))` だと `[(0, 30), (1, 10), (2, 20)]` になる。
- **ソートする前にインデックスを付ける。** `enumerate(sorted(A))` では、元の位置ではなくソート後の番号になる。
- `pairs.sort()` はpairsを直接変更し、返り値はNone。`pairs = pairs.sort()` と書かない。
- 別のリストとしてソート結果が欲しければ `sorted_pairs = sorted(pairs)`。
- 重複する値も別々の組として残る。`[10, 10]` は `[(10, 0), (10, 1)]`。
- 空の配列なら `[]` を返す。
- N要素の組のリスト作成は時間O(N)、追加領域O(N)。ソートは時間O(N log N)。
- 整数・文字列などの比較可能な値を想定。ソートできない型同士を混ぜない。
## よく使う応用
### 値は降順、同じ値なら元の番号の昇順
```python
A = [20, 10, 20]
pairs = [(x, i) for i, x in enumerate(A)]
pairs.sort(key=lambda p: (-p[0], p[1]))
# [(20, 0), (20, 2), (10, 1)]
```
数値向け。`pairs.sort(reverse=True)` では同じ値のインデックスも降順になる点に注意。
### ソートした順番で元の番号を出力する
```python
A = [30, 10, 20]
pairs = [(x, i) for i, x in enumerate(A, start=1)]
pairs.sort()

print(*(i for x, i in pairs))
# 2 3 1
```
## enumerateの仕組み
```python
A = [30, 10, 20]
for i, x in enumerate(A):
    print(i, x)
# 0 30
# 1 10
# 2 20
```
enumerateは番号と値の組を順に取り出すイテレータ。importは不要。内包表記で全要素を取り出して、値を先頭にしたタプルをリストに格納している。
`start=1` は番号を1から付ける指定であり、2番目の要素から読み始める指定ではない。
