## ページの構成 {toggle="true"}
	ページを作るときは、次の8項目の順で整理する。
	1. テンプレ
	2. テンプレの使い方
	3. 使う場面
	4. 注意事項
	5. 具体的な問題への適用例
	6. 計算量
	7. よくあるミス
	8. 関連
## 項目の分け方・表示方法 {toggle="true"}
	- 特定の問題名・問題固有の入力形式・解答コードを含む例は「具体的な問題への適用例」にまとめる。「それの使い方」には、引数・戻り値と短い汎用的な使用例を書く。
	- 「関連」には問題や関連ページへのリンクを置き、詳しい適用手順や解答コードは「具体的な問題への適用例」に分離する。
	- 具体的な問題への適用例は、無理に作る必要はない。あれば書く程度。
	- 各項目はトグル見出しにし、項目ごとに開閉できるようにする。本文・コード・表も、そのトグルの中にまとめる。
	- 「具体的な問題への適用例」が複数ある場合は、項目内でさらに問題ごとのトグルに分ける。
## コードの記載ルール {toggle="true"}
	- Python 3 / AtCoderを前提にする
	- 各コード例は手元の共通テンプレートのsetup実行後に使う。共通テンプレートと重複するimportは書かず、追加で必要なimportだけを各コード例に残す。
	- 共通で利用できるもの：`sys`、`math`、`deque`、`defaultdict`、`Counter`、`heappush`、`heappop`、`permutations`、`combinations`、`product`、`bisect_left`、`bisect_right`、`DSU`、`FenwickTree`、`SegTree`、`LazySegTree`。
	- 数学関数は `math.isqrt`・`math.gcd` のように `math.` を付ける。`from math import ...` は重ねて書かない。
	- `input = sys.stdin.readline` と再帰上限 `sys.setrecursionlimit(10**7)` は共通テンプレートで設定済み。問題固有の変更が必要なときだけ追加する。
	- `sortedcontainers` など共通テンプレートにないライブラリのimportは残す。
	- そのまま貼るコードは入力形式や0-indexed / 1-indexedの前提を明記する
